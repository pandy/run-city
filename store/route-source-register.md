## 每条路线的发布门槛

1. 轨迹文件来源、作者、许可或书面授权可追溯。
2. 导入后距离与页面标示的距离相差不超过 3%。
3. 实跑验证起终点、过街点、封闭区域、厕所、补给与夜间照明。
4. 填写核验日期、核验人和失效复查日期。
5. 若路线改变、施工或封路，立即下线或标为“待复核”。

## O-001 路线生成记录

- 路径引擎：基于 OpenStreetMap 的公开路网路由。
- 范围：当前上海 10 条路线；每条均执行“无渡轮、长度不超过 25 km”自动校验。
- 发布要求：App 地图内展示 `© OpenStreetMap contributors`，并在发布前完成每条路线的实跑复核。
- 注意：OSM 路网解决的是数据许可与可追溯性，不保证临时施工、园区开放时间和跑步安全；这些仍须现场更新。

## 导入命令

将 GPX 放在本机任意位置后，在 `mobile` 目录运行：

```bash
npm run inspect:gpx -- /完整路径/route.gpx
```

该命令只读取并分析轨迹，不会上传或发布数据。输出的距离、起终点、边界和坐标将用于地图复核。
