跑城使用条款

生效日期：2026-08-05

使用跑城即表示你同意本使用条款。若你不同意本条款，请停止使用本 App。

服务说明

跑城提供城市跑步路线浏览、路线信息展示、收藏和本地跑步记录辅助管理等功能。路线信息仅供参考，不构成安全、医疗、训练或专业建议。

户外运动风险

跑步和户外运动存在道路、天气、交通、照明、身体状态等风险。你应根据自身健康状况、现场环境和当地规则独立判断是否适合跑步，并自行承担运动风险。

路线信息

我们会尽力提供准确的路线信息，但路线开放状态、道路施工、临时管制和环境条件可能变化。出行前请结合现场情况和官方信息确认。

禁止行为

你不得滥用跑城、干扰服务运行、尝试逆向攻击系统、侵犯他人权利，或将路线信息用于违法用途。

服务变更

我们可能更新、调整、暂停或终止部分功能。我们会尽量保持服务稳定，但不保证服务始终无错误或不中断。

免责声明

在法律允许的范围内，跑城不对因使用或无法使用本 App、依赖路线信息、参与户外运动而产生的间接损失或人身风险承担责任。

联系我们

如有问题，请通过 GitHub Issues 联系我们。
